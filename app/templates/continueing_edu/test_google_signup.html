4. Database Check

หลังจากทดสอบแล้ว ตรวจสอบข้อมูลใน database:

# เข้า Python shell flask shell # Query ข้อมูล from app.continuing_edu.models import Member from sqlalchemy import desc # ดู Member ล่าสุดที่ลงทะเบียนด้วย Google members = Member.query.filter(Member.google_sub.isnot(None)).order_by(desc(Member.created_at)).limit(5).all() for m in members: print(f"ID: {m.id}, Username: {m.username}, Email: {m.email}") print(f"Google Sub: {m.google_sub}") print(f"Connected: {m.google_connected_at}") print(f"Verified: {m.is_verified}") print("-" * 50)

5. Expected Results

✅ Success Indicators:

  • Google popup แสดงขึ้นเมื่อคลิกปุ่ม
  • เลือก account แล้วไม่มี error
  • Redirect ไปหน้า Complete Profile สำหรับผู้ใช้ใหม่
  • ข้อมูล google_sub ถูกบันทึกใน database
  • google_connected_at มีค่า timestamp
  • is_verified = True (Google email verified)
  • Login ครั้งต่อไปใช้ Google ได้ทันที
⚠️ Note: Google Client ID ที่ใช้เป็น development key. ถ้าจะใช้งานจริง ต้อง:
  • สร้าง Google Cloud Project ใหม่
  • Enable Google Sign-In API
  • ตั้งค่า OAuth consent screen
  • เพิ่ม authorized redirect URIs
  • อัปเดต GOOGLE_CLIENT_ID ใน .env

6. Troubleshooting

🔧 Common Issues:

Problem Solution
Google button ไม่แสดง Check console errors, verify Google Client ID
Redirect ไม่ทำงาน ตรวจสอบ callback route ใน views.py
Database error ตรวจสอบว่ารัน migration แล้ว
JWT decode error Install PyJWT: pip install PyJWT
